# Mini Incubadora Portátil - UFU

Projeto acadêmico desenvolvido para a disciplina de programação em Engenharia Biomédica na Universidade Federal de Uberlândia.

## 🛠️ Tecnologias e Componentes
- **Placa:** ESP32
- **Sensor:** DHT22 (Temperatura e Umidade)
- **Display:** LCD I2C (16x2)
- **Atuadores:** LEDs para indicação de aquecimento/resfriamento

## 📌 Funcionalidades
- Leitura em tempo real de temperatura e umidade.
- Exibição de dados no display LCD.
- Servidor Web local (192.168.4.1) para monitoramento remoto via Wi-Fi.
